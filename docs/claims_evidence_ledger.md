# Document 1: Claims-to-Evidence Audit Ledger (NOSIH — CyberForge Hackathon 2026)

## 1. Purpose of This Ledger for Judges & Reviewers

In security research and competitive engineering hackathons, reviewers rightfully challenge quantitative metrics to determine whether reported numbers are **verified empirical facts from primary literature**, **supported analytical inferences**, or **planned prototype evaluation targets**. This ledger maps every factual, architectural, and quantitative claim in the **NOSIH (Non-ambient Origin-Scoped Intent Harness)** research report and PRD to its exact primary source, specific document location (page, section, figure, or table), and formal epistemic classification.

## 2. Epistemic Classification Taxonomy

| Epistemic Status | Formal Definition | Audit Requirement |
| :--- | :--- | :--- |
| **Verified Fact** | Directly measured or documented in a peer-reviewed paper, arXiv benchmark preprint, NVD CVE record, or official standard/event specification. | Must cite exact URL, publication date, and specific paper section, table, or figure. |
| **Supported Inference** | Logically derived by combining two or more verified primary findings (e.g., applying a documented attack vector to a protocol specification that lacks a corresponding control). | Must explicitly show the premises and the technical derivation chain. |
| **Planned Target** | Quantitative design objective or benchmark SLA targeted for the 24-hour NOSIH prototype evaluation suite (`nosih bench`). | Must never be conflated with prior literature results; must specify the exact test harness used to measure it. |
